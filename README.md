# Multi-Agent Systems Assignment 3 - Question 1

Course: AI3403 - Multi Agent Systems

## Description
Formation control simulation using consensus-based dynamics. 20 agents form the letters "HARSH" sequentially. The target formation points are extracted from input images for more flexibility.

## Running the script
```bash
python main.py
```
Requires: numpy, matplotlib, networkx, scipy, pillow, ffmpeg (for mp4) (fallbacks to PIL if not available)
